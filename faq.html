Frequently asked questions

Quick answers about All Browser Cleaner.

Is All Browser Cleaner free?

Yes. The app is free to download and use. It is supported by small, clearly labelled sponsor banners shown inside the app, and by voluntary support from users on Ko-fi. Paying is never required, and support does not unlock features or remove the banners — it is simply a way to say thank you.

Which browsers does it clean?

Every browser installed on your PC. Detection is fully automatic — Chrome, Edge, Brave, Firefox, Opera, Vivaldi, DuckDuckGo and others are found on their own, including browsers you add yourself. If a browser is installed, it can be cleaned.

Will it delete my bookmarks or extensions?

No. Bookmarks and extensions are never removed by normal cleaning. Saved passwords and extension storage are off by default and ask for an extra confirmation before they can even be selected.

What exactly does it clean?

Browsing and download history, cookies, cache, site storage, site settings & permissions, and autofill form data — only for the browsers and data types you tick. At the end, a summary shows what was cleaned and how much space was freed, per browser and per data type.

Will it close my browsers?

Only the browsers you selected for cleaning are closed, because a browser's data can only be cleared safely while it is not running. Browsers you leave unticked are never closed and never modified — and any browser can be locked with the Protect option in Settings, so it can never be cleaned by accident.

Does it upload my data anywhere?

No. All cleaning happens on your own PC. The app collects nothing, has no accounts and uploads nothing. The only thing it ever downloads is the small sponsor banner (a configuration file and images) from our public GitHub page when it starts — a one-way download that sends no information about you. See the Privacy Policy for the full detail.

Why does Windows show a SmartScreen warning?

All Browser Cleaner is new software, so on first run Windows SmartScreen may say "Windows protected your PC" because the file is not commonly downloaded yet. This is normal for new independent software. Click More info → Run anyway to continue, and if Edge shows a download warning, choose Keep anyway. You can also click "Report this app as safe" — it helps the warning go away for everyone over time. You can skip this warning entirely by installing from the Microsoft Store — the Store version is signed by Microsoft.

Which Windows versions are supported?

Windows 10 and Windows 11.

How do I support the project?

If the app saves you time, you can support its development on Ko-fi: ko-fi.com/verokod. Support is completely voluntary.
